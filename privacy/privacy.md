# Privacy Policy — Liz Briefing

*Last updated: October 8, 2026*

Liz Briefing is a private, self-hosted application that assembles a short daily summary
for two named people in one household. It is not a commercial product, it has no public
sign-up, and no one outside those two Google accounts can access it.

## What it accesses

With explicit Google consent, and read-only in both cases:

- **Google Calendar** (`calendar.readonly`) — event titles, times, locations and calendar
  names for the current day only.
- **Gmail** (`gmail.readonly`) — for inbox messages received in the previous 24 hours, the
  sender, subject, date, and the short preview snippet Gmail itself generates.

It never sends, modifies, labels or deletes mail, and never creates or changes a calendar
event. It does not read message bodies or attachments.

## How that information is used

Solely to produce one plain-language summary of the day ahead, shown on a private web page.
There is no other use, and no secondary processing of any kind.

## Where it runs, and who can see it

On a server on a private residential network. The page requires Google sign-in and is
restricted to an explicit allowlist of two email addresses; every request is authenticated
before any data is returned.

The summary wording is generated by a language model running on separate hardware on that
same private network. Calendar and email details are not transmitted to any third-party
model provider, analytics service, advertiser or data broker. They are never sold, and
never shared with anyone outside the two account holders.

## What is stored, and for how long

- The generated summary text, kept until the next day's replaces it.
- The Google OAuth token, stored on that private server so the briefing can run each
  morning without a prompt, until access is revoked.
- No copies of email bodies, attachments, full message content, or calendar history are
  retained at any point.

## Limited Use

Liz Briefing's use of information received from Google APIs adheres to the
[Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy),
including the Limited Use requirements.

## Revoking access

Access can be withdrawn at any time at
[myaccount.google.com/permissions](https://myaccount.google.com/permissions) by removing
"Liz Briefing Data". The application immediately loses all access to Google data; nothing
further is required.
